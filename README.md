# 🛍️ Customer Behavior Analytics Dashboard

## 📌 Project Overview

This project analyzes customer shopping behavior data using Python, SQL, and Power BI to uncover purchasing patterns, customer segments, and revenue drivers. The goal is to transform raw data into actionable business insights through data analysis and interactive dashboards.

## 🔄 Project Workflow

1. Data Collection & Loading
2. Data Cleaning & Preprocessing
3. Exploratory Data Analysis (EDA)
4. SQL Analysis
5. Power BI Dashboard Development
6. Business Insights & Recommendations
7. Report & Presentation Creation

## 📊 Dashboard Features

* Total Customers KPI
* Average Purchase Amount
* Average Review Rating
* Revenue by Category
* Sales by Category
* Revenue by Age Group
* Interactive Filters & Slicers

## 💡 Key Insights

* Clothing generated the highest revenue.
* Young Adults contributed the most sales.
* Subscription customers showed higher engagement.
* Average purchase value exceeded $50.
